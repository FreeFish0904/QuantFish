1　平台是什么，解决什么问题

QuantFish 最初是一个课堂作业平台：学生上传 generate_signals.py，平台在隐藏行情上评分， 榜单排出全班的相对水平。它后来长成了一条完整的研究闭环 —— 数据发布、时点正确的撮合引擎、 队列化评分 worker、结果过期检测，以及一个跑真实引擎的演示环境。

它替换掉的手工流程

传统做法QuantFish 的做法
助教本地跑脚本，结果散落在各自电脑提交即入队，独立进程评分，产物统一落在 reports/<submission-id>/
「年化收益」各处口径不一，无法横向比较指标只在 metrics.py 算一次，写入 summary.csv 并镜像到 API
学生只看到最终分数，不知道错在哪详情页给出指标、分组收益、分年表现、执行参数与错误原文
改了数据或参数后旧成绩仍被当作可比每次运行记录配置与数据指纹，变化后自动标记 stale
课堂断网就没法做作业可导出学习数据包与 conda 离线运行时（含依赖签名清单）

四个「不是玩具」的地方

  • 引擎是真的。前复权价格、T+1 VWAP 成交、涨跌停与停牌规则、参与率上限、 佣金／滑点／印花税；long-only 路径按排名加权并计算 beta 调整后的主动收益。
  • 平台是真的。FastAPI + SQLite + 线程／进程评分队列、parquet 面板缓存、 作业进度流式输出、过期结果检测、管理后台、班级分组、学生数据导出、离线运行时打包。
  • 测试是真的。387 个后端测试与 224 个前端测试，前后端各有 CI 门槛。
  • 演示是诚实的。公开演示是静态构建 + 浏览器内 mock；Docker 演示会生成一份合成 CSMAR 风格数据，并真的跑引擎、队列和报告生成器。
数据说明：仓库不分发行情数据。演示与 CI 使用 scripts/gen_sample_dataset.py 生成的合成数据集（模拟价格、成交量、行业，以及一个故意偏弱的嵌入信号）， 不含任何真实市场信息；真实部署把 data_releases.raw_data_root 指向授权的 CSMAR 风格导出。
