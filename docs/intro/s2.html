2　三类使用者看到的功能

角色主要界面与能力
学生 团队登录 · 下载学习数据与学习材料 · 上传策略（learning / hidden_test 赛道）· 轮询运行状态（queued → running → completed）· 查看指标、评分拆解、净值/回撤/分组收益图 · 分年表现表 · 多次提交对比 · 下载离线环境包
教师 / 管理 管理团队与提交 · 编辑平台设置（单一配置树 + 交叉校验）· 评分权重与超时 · 查看学生源码与报错原文 · 导出学生数据 · 重跑与清理
维护者 维护数据发布（learning / learning_1..3 / hidden_test）· 引擎与队列 · 运行时仓储 · 离线运行时包 · 由运行中应用自动生成的 API 契约（api-types.ts）

页面组成（前端按路由分特性，一个目录一块屏）

页面内容
Dashboard课程状态、评分器状态、KPI、最新提交
Submit Strategy团队凭据、赛道选择、上传、状态轮询、数据与环境下载
Leaderboard每队最佳成绩排名
History全部提交、筛选、过期状态、勾选对比
Submission Detail指标卡与指标表、评分拆解、图形数据、执行参数、分年表现
Compare多份提交的净值、回撤、分组收益与执行参数对照
Admin Console设置、团队、提交与相关管理面板
