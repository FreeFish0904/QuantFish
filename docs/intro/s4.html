4　指标：两套口径并列，永不混用

同一个回测同时给出两种收益基准。它们都来自同一条日收益序列， 因此不会对「哪天交易了」有分歧，只对「怎么聚合」有分歧。

口径字段用途
算术
简单收益相加		 all_return / total_return、annual_return、 max_drawdown、calmar、fitness 等
即 \(R=\sum_{i=1}^{n} r_i\)，\(A=R\cdot 252/n\)		 评分、排名、过期检测。评分权重就是在这些数值上调出来的。
几何
复利净值		 compounded_total_return、cagr、 compounded_max_drawdown、compounded_calmar、 volatility、sortino、t_stat、t_stat_p_value 报告与对外解释。这是外部平台或审阅者会用的定义。

八个几何口径字段

字段定义
compounded_total_return\(\prod_{i=1}^{n}(1+r_i)-1\)，账户真正会持有的累计收益
cagr\(\left(\prod_{i=1}^{n}(1+r_i)\right)^{252/n}-1\)，复合年增长率
compounded_max_drawdown复利净值 \(V_i=\prod_{j\le i}(1+r_j)\) 的峰谷回撤 \(\max_i\left(1-\dfrac{V_i}{\max_{j\le i}V_j}\right)\)（把初始 1.0 计为峰），以正数报告
compounded_calmar\(\text{cagr} / d^{\text{cmpd}}_{\max}\)，即复合年增长率 ÷ 复合最大回撤
volatility\(\sqrt{252}\,\operatorname{std}(r,\ \text{ddof}=1)\)，年化波动率
sortino\(\dfrac{\sqrt{252}\,\operatorname{mean}(r_i-r_f^{d})}{\sqrt{\operatorname{mean}\left(\min(r_i-r_f^{d},\,0)^2\right)}}\)，MAR = long_only_risk_free_rate（默认 1.75%/年）
t_stat\(t=\sqrt{n}\,\dfrac{\overline{r}}{\operatorname{std}(r,\ \text{ddof}=1)}\)，均值日收益的 t 统计量
t_stat_p_value\(p=\operatorname{erfc}\!\left(\dfrac{|t|}{\sqrt{2}}\right)\)，正态近似下的双侧 p 值（不引入 SciPy）

算不出来就报 null，不报 0 也不报 inf

情形结果
观测数 n < 2volatility / sortino / t_stat / t_stat_p_value 为 null；收益与 CAGR 照常
任一天 ≤ −100%（本金归零）整个复利块为 null，算术字段不受影响
全样本收益恰好为 0cagr = 0、volatility = 0；sortino / t_stat 为 null（分母为 0）
没有任何一天低于 MARsortino 为 null（无穷大不是测量结果）
历史报告早于这些字段API 返回 null，界面回落到 annual_return，无需重跑
