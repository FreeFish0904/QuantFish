6　技术组成与仓库结构

层组成
前端React 19 + TypeScript + Vite；按路由划分 feature 目录；手写 SVG 图表；中英双语字典；测试用 vitest + Testing Library + MSW
后端FastAPI + Pydantic；特性内聚的路由（submissions / leaderboard / compare / admin / downloads）；SQLite 与 JSON 仓储
引擎pandas + pyarrow；面板构建与缓存、撮合、行业中性化、指标与图形数据
评分线程／进程队列，score_worker 子进程，超时与并发上限来自配置
报告summary.csv / graph_data.json / 分年 CSV / parquet；可选 PDF（weasyprint + Noto CJK）
交付Docker 多阶段构建；GitHub Actions（CI 矩阵 + Pages 静态演示）

目录一览

backend/src/quantfish/   FastAPI 应用、回测引擎、评分队列、数据发布、导出
backend/tests/           pytest 测试集
frontend/                React 19 + Vite 单页应用（features/* = 一个目录一块屏）
frontend/src/mocks/      MSW 处理器，同时驱动测试与静态演示
config/                  platform.yaml（课堂）与 platform.demo.yaml（演示）
deploy/                  Dockerfile、compose、entrypoint、演示数据播种
docs/                    架构、指标定义、学生手册、截图
examples/                可直接运行的示例策略
scripts/                 数据集生成、启动器、备份、离线运行时打包
data/                    生成的数据集目录（git 忽略）

三种运行方式

方式命令你会得到
Docker
推荐		 docker compose -f deploy/docker-compose.yml up --build 生成合成数据、构建数据发布、跑两份真实回测，打开 http://localhost:8010
本地开发 pip install -e './backend[dev,pdf]' · npm --prefix frontend install · scripts/start-quantfish.sh --mode dev API + Vite 热更新；--mode prod --port 8010 跑生产构建
纯静态演示 VITE_DEMO_MODE=true npm --prefix frontend run build MSW 接管全部 REST 接口、hash 路由、无需后端即可托管（线上演示就是这样部署的）
