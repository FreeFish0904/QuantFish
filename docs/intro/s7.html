已知边界（不粉饰）

  • t 统计量与 p 值不做自相关修正；持仓重叠或流动性差的策略会高估显著性，它只适合做初步筛选。
  • 几何口径的极端情形（本金归零、无下行日）按 null 处理，不做数值填补。
  • 仓储仍是 SQLite / JSON，多机部署与在线迁移尚未接入（见 Roadmap：Postgres + Alembic）。
  • 公开演示是 mock 数据，只能验证交互与展示；要看真实回测请用 Docker 方式。
