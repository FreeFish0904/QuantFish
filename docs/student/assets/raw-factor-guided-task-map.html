从原始数据到 longshort 权重

这不是答案页，而是一张引导地图：学生需要自己补字段、补公式、检查方向，最终得到一张正负都有的 weighted_score 列表。

边界很重要

本任务停在 score → centered_score → weighted_score。还没有乘以今天 VWAP，也没有计算股数、成交、收益或交易成本。

1

读一天截面

从 daily_returns 读出某个交易日的股票列表、价格、成交额和 markettype。

2

问投资直觉

先写清楚“什么股票应该高分”，再决定使用哪些字段。

3

计算 score

用 pandas / numpy 造中间列，标准化后合成原始因子分数。

4

归一化权重

去均值，再除以绝对值总和，得到正负都有的 weighted_score。

5

检查 top/bottom

打印 top 20 和 bottom 20，但完整组合是所有股票的权重表。

高分不是答案

score 只是排序依据；它还不是仓位。学生要解释自己的高分股票为什么应该排前面。

去均值才产生多空

高于平均分变成正的 centered_score；低于平均分变成负的 centered_score。

不要跨进成交系统

weighted_score 出来后先停住。VWAP、股数、成本和收益是下一节课。

1. 原始分数 score = 因子组合
2. 去均值 centered = score - mean(score)
3. 归一化 weighted = centered / sum(abs(centered))

最终检查

  • 完整表是否包含所有有效股票？
  • weighted_score 是否有正有负？
  • 正权重合计是否约为 +0.5？
  • 负权重合计是否约为 -0.5？
  • 绝对值总和是否约为 1.0？
  • top 20 / bottom 20 是否符合因子直觉？

停止线

  • 还不计算买卖多少股。
  • 还不把权重乘以资金。
  • 还不使用今天 VWAP 成交。
  • 还不计算 VWAP 到收盘的收益。
  • 先把排序和权重逻辑讲清楚，再进入回测引擎。

课堂使用建议：先让学生完成引导版，再让他们对照完整实验版；如果 top/bottom 不符合直觉，问题在 score；如果正负权重不对，问题在 weighted_score；权重对但收益不对，才进入 VWAP 与回测引擎。
